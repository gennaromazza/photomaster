Ecco i principali bug rimanenti e le correzioni necessarie:

Conflitto nella Creazione del Secondo Cliente:

Il form del secondo cliente riutilizza lo stesso form e mutation del primo, causando sovrascrittura dei dati.

Soluzione: Creare un form e mutation separati per il secondo cliente.

tsx
Copy
// Aggiungi un nuovo form per il secondo cliente
const secondClientForm = useForm<ClientFormValues>({
  resolver: zodResolver(clientFormSchema),
  defaultValues: { /* ... */ }
});

// Crea una mutation separata per il secondo cliente
const createSecondClientMutation = useMutation({
  mutationFn: /* ... */,
  onSuccess: (newClient) => {
    // Imposta il secondo clientId
    form.setValue("secondClientId", newClient.id);
    // Reset e chiusura dialog
  }
});
Checkbox Collaboratori non Aggiornati:

Gli input checkbox non riflettono lo stato corrente degli assegnatari.

Correzione: Aggiungere checked basato sullo stato del form.

tsx
Copy
<input 
  type="checkbox"
  checked={(form.watch("assignedCollaborators") || []).includes(collaborator.id)}
  onChange={/* ... */}
/>
Reset Form alla Chiusura Dialog:

I form rimangono popolati dopo la chiusura dei dialog.

Correzione: Resettare i form negli handler onOpenChange.

tsx
Copy
<Dialog 
  open={isClientDialogOpen} 
  onOpenChange={(open) => {
    setIsClientDialogOpen(open);
    if (!open) clientForm.reset();
  }}
>
Gestione Stato Dialog Secondo Cliente:

Manca lo stato per controllare l'apertura/chiusura del dialog del secondo cliente.

Aggiungere:

tsx
Copy
const [isSecondClientDialogOpen, setIsSecondClientDialogOpen] = useState(false);
Selezione Cliente Secondario non Funzionante:

La creazione del secondo cliente non aggiorna il campo secondClientId.

Assicurarsi che la mutation del secondo cliente aggiorni il campo corretto.

File Corretto (estratti salienti):

tsx
Copy
// Form separati e mutation per secondo cliente
const secondClientForm = useForm<ClientFormValues>({
  resolver: zodResolver(clientFormSchema),
  defaultValues: { /* ... */ }
});

const createSecondClientMutation = useMutation({
  mutationFn: async (data: ClientFormValues) => {
    const res = await apiRequest("POST", "/api/clients", data);
    return res.json();
  },
  onSuccess: (newClient) => {
    queryClient.invalidateQueries({ queryKey: ["/api/clients"] });
    secondClientForm.reset();
    setShowSecondClientSuccess(true);
    setTimeout(() => {
      setShowSecondClientSuccess(false);
      setIsSecondClientDialogOpen(false);
      form.setValue("secondClientId", newClient.id); // <-- Imposta il secondo client
    }, 2000);
  },
  // ...
});

// Nel JSX del secondo cliente:
<Dialog 
  open={isSecondClientDialogOpen} 
  onOpenChange={setIsSecondClientDialogOpen}
>
  {/* Usa secondClientForm e createSecondClientMutation */}
  <Form {...secondClientForm}>
    <form onSubmit={secondClientForm.handleSubmit(createSecondClientMutation.mutate)}>
      {/* ... */}
    </form>
  </Form>
</Dialog>
Checkbox Collaboratori Corretti:

tsx
Copy
<input 
  type="checkbox"
  checked={(form.watch("assignedCollaborators") || []).includes(collaborator.id)}
  onChange={(e) => {
    const current = form.getValues("assignedCollaborators") || [];
    form.setValue(
      "assignedCollaborators",
      e.target.checked 
        ? [...current, collaborator.id] 
        : current.filter(id => id !== collaborator.id)
    );
  }}
/>
Pulizia Form alla Chiusura Dialog:

tsx
Copy
<Dialog

  onOpenChange={(open) => {

      clientForm.reset();
      setShowClientSuccess(false);
    }
  }}
